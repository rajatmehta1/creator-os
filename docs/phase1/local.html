Local Development

Run Without Docker

Install and run every service natively on your machine

Scope Design Quick Start How to Use Local Setup Deploy

Overview

This guide walks you through installing every service directly on your machine — no Docker required. This gives you maximum control, faster hot-reload, and easier debugging, but requires installing each dependency manually.

Estimated time: ~30 minutes for first-time setup. After that, starting the full stack takes under a minute.

One-Script Startup (Optional)

Create a startup script to launch everything at once:

macOS / Linux — start-local.sh

start-local.sh 
#!/bin/bash
# Start all Creator OS services locally

echo "Starting ChromaDB..."
chroma run --host 0.0.0.0 --port 8100 --path ./chroma_data &

echo "Starting Backend..."
cd backend
source .venv/bin/activate
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000 &

echo "Starting Celery Worker..."
celery -A tasks.celery_app worker -l info &

echo "Starting Celery Beat..."
celery -A tasks.celery_app beat -l info &

echo "Starting Frontend..."
cd ../frontend
npm run dev &

echo ""
echo "All services started!"
echo "  Backend:  http://localhost:8000"
echo "  Frontend: http://localhost:3000"
echo "  Neo4j:    http://localhost:7474"
echo ""
echo "Press Ctrl+C to stop all services"
wait

Minimal Setup (Skip Optional Services)

If you want to get running quickly with just the core features, you can skip Neo4j and ChromaDB initially. The app will start but some features won't work:

Service SkippedWhat BreaksEverything Else Still Works
Neo4j Knowledge graph endpoints (/graph/*), content gap analysis, topic authority All agents, trends, ideas, scripts, SEO, analytics, media kit
ChromaDB Semantic search, Creator DNA embeddings storage, content similarity All agents still run (just without vector search), all UI works
Celery Scheduled tasks (auto trend polling, analytics sync, DNA rebuild) Everything works on-demand — you just trigger manually
Minimum viable stack: PostgreSQL + Redis + Backend + Frontend. That's 4 services and gives you auth, all 6 agents, content pipeline, and the full dashboard. Add Neo4j, ChromaDB, and Celery later when you need them.

Troubleshooting

asyncpg can't connect

Make sure PostgreSQL is running and accepting connections on port 5432. Check pg_hba.conf allows local password auth (md5 or scram-sha-256).

Redis connection refused

Verify Redis is running: redis-cli ping. On Windows, make sure your Redis instance (WSL or Memurai) is started.

Neo4j auth error

On first launch, Neo4j forces a password change. Open http://localhost:7474, log in with neo4j/neo4j, and set your password to match .env.

Celery won't start on Windows

Install eventlet: pip install eventlet and use --pool=eventlet. Or run Celery inside WSL2.

pgvector not found

CREATE EXTENSION vector fails if pgvector isn't installed for your PostgreSQL version. Re-check the install step for your OS.

Port already in use

Another process is using the port. Find it with netstat -ano | findstr :PORT (Windows) or lsof -i :PORT (macOS/Linux) and stop it.
