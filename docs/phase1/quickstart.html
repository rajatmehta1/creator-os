Prerequisites

Before starting, make sure you have the following installed on your machine:

ToolVersionPurpose
Docker Desktop4.25+Runs all 7 services in containers
Docker Composev2.20+Included with Docker Desktop
Git2.40+Clone the repository
Node.js20 LTSFrontend development (optional for Docker-only setup)
Python3.12+Backend development (optional for Docker-only setup)
Docker-only option: If you just want to run the platform, you only need Docker Desktop. Node.js and Python are only needed if you plan to develop outside Docker.
1

Clone the Repository

Clone the project to your local machine:

Terminal 
git clone <repository-url> creator-os
cd creator-os
2

Configure Environment Variables

Copy the example environment file and fill in your API keys:

Terminal 
cp .env.example .env

Open .env in your editor and configure these required variables:

VariableRequiredHow to Get It
ANTHROPIC_API_KEY Yes Sign up at console.anthropic.com and create an API key
OPENAI_API_KEY Yes Sign up at platform.openai.com and create an API key
YOUTUBE_CLIENT_ID Yes Google Cloud Console → APIs & Services → Credentials → Create OAuth 2.0 Client
YOUTUBE_CLIENT_SECRET Yes Same as above; copy the client secret
NEXTAUTH_SECRET Yes Generate with: openssl rand -base64 32
SECRET_KEY Yes Generate with: openssl rand -hex 32
REDDIT_CLIENT_ID Optional Reddit app preferences → Create application (script type)
NEWS_API_KEY Optional Sign up at newsapi.org
YouTube OAuth Setup: In Google Cloud Console, make sure to:
  • Enable the YouTube Data API v3 and YouTube Analytics API
  • Add http://localhost:8000/api/v1/auth/callback as an authorized redirect URI
  • Add http://localhost:3000 as an authorized JavaScript origin
3

Launch All Services

Start the entire platform with Docker Compose:

Terminal 
# Build and start all services (first run takes a few minutes)
docker compose up --build

# Or run in detached mode (background)
docker compose up --build -d

Docker Compose will start 7 services. Wait for all health checks to pass:

Local Development (Without Docker)

For faster development iteration, you can run the backend and frontend natively:

Backend Setup

Terminal — Backend 
# Navigate to backend
cd backend

# Create virtual environment
python -m venv .venv

# Activate (Windows)
.venv\Scripts\activate

# Activate (macOS/Linux)
source .venv/bin/activate

# Install dependencies
pip install -e ".[dev]"

# Start databases (keep these in Docker)
docker compose up postgres redis neo4j chroma -d

# Run migrations
alembic upgrade head

# Start the API server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

Celery Workers (Separate Terminal)

Terminal — Celery 
# Start Celery worker
celery -A tasks.celery_app worker --loglevel=info

# Start Celery Beat scheduler (another terminal)
celery -A tasks.celery_app beat --loglevel=info

Frontend Setup

Terminal — Frontend 
# Navigate to frontend
cd frontend

# Install dependencies
npm install

# Start dev server
npm run dev

  - Ready in 2.5s

Troubleshooting

Port Already in Use

Error: Bind for 0.0.0.0:8000 failed: port is already allocated

Another service is using the port. Stop it or change the port mapping in docker-compose.yml:

Terminal 
# Find what's using port 8000
netstat -ano | findstr :8000    # Windows
lsof -i :8000                   # macOS/Linux

Database Connection Failed

Error: Connection refused to localhost:5432

PostgreSQL may not be ready yet. Wait for the health check or check logs:

Terminal 
docker compose logs postgres
# Wait for: "database system is ready to accept connections"

Neo4j Authentication Failed

If Neo4j fails to connect, ensure the credentials match between .env and docker-compose.yml. Default: neo4j / creatorOSgraph.

Celery Tasks Not Running

Check that Redis is up and the Celery worker is connected:

Terminal 
docker compose logs celery-worker
# Should show: "celery@... ready."
# And list registered tasks

Frontend Can't Reach Backend

Make sure NEXT_PUBLIC_API_URL in the frontend is set to http://localhost:8000 (or the backend container name if both are in Docker).

Full Reset

If everything is broken, nuke it all and start fresh:

Terminal — Nuclear Option 
# Stop everything, delete volumes, remove images
docker compose down -v --rmi local

# Rebuild from scratch
docker compose up --build

# Re-run migrations
docker compose exec backend alembic upgrade head
