Dependency Injection Pattern

All dependencies are injected via FastAPI's Depends() system with type aliases:

# dependencies.py
DbSession   = Annotated[AsyncSession, Depends(get_db)]
RedisClient = Annotated[Redis, Depends(get_redis)]
CurrentUser = Annotated[User, Depends(get_current_user)]

# Usage in endpoints:
@router.get("/trends")
async def get_trends(db: DbSession, user: CurrentUser, redis: RedisClient):
    ...

LLM Factory Pattern

All LLM access goes through a single factory at app/core/llm.py:

# Never instantiate LLM clients directly — always use:
llm = get_llm(model="claude-sonnet-4-20250514", streaming=True, temperature=0.7)

# Automatic fallback: Claude → OpenAI
# Built-in retry: 3 attempts with exponential backoff (2–30s)
# Token counting and cost tracking included

Agent Architecture (LangGraph)

Each agent is a LangGraph StateGraph — a directed graph of processing nodes with typed state. Nodes are async functions that transform state. Edges define execution order, with support for parallel fan-out and conditional routing.

Trend Scout Agent

7 nodes with parallel data fetching:

START → Google Trends Reddit YouTube News → Score → Cluster → Recommend → END

Four data sources are fetched in parallel, then scored for niche relevance, clustered by semantic similarity (cosine > 0.7), and converted into actionable recommendations.

Idea Generator Agent

7 nodes with parallel brainstorming:

START → Gap Analysis Trend Ideas Evergreen Ideas → Cross-Pollinate → Score → Diversify → Human Gate → END

Script Architect Agent

7 nodes, sequential with DNA conditioning:

START → Research → Outline → Draft + DNA → Inject Hooks → Tone Check → Variants → Human Gate → END

The draft is written using the creator's DNA fingerprint. If the tone check scores below 7.0/10, the draft is automatically rewritten. Variants are generated for 6 platforms.

SEO Optimizer Agent

9 nodes with two parallel fan-out stages:

START → Keywords → Competitors Search Intent → Titles Desc Tags Thumbs Blog SEO → Score → END

Performance Analyst Agent

START → Sync Data → Compute Metrics → Detect Patterns Benchmark → Insights → Agent Feedback → Update Graph → END

Orchestrator (Supervisor Agent)

Routes requests and manages full pipelines with conditional agent chaining:

Route → Trend Scout → Idea Gen? → Script Arch? → SEO Opt? → Finalize

Supports three modes: full_pipeline (all agents), single_agent (one specific agent), and custom (user-selected subset).

Seven node types with rich relationships:

(:Creator)  -[:CREATED]->       (:Content)
(:Content)  -[:COVERS]->        (:Topic)
(:Content)  -[:USES_KEYWORD]->  (:Keyword)
(:Topic)    -[:RELATED_TO]->    (:Topic)

Key queries: content gap analysis (topics with few content pieces), topic authority scoring (depth + breadth of coverage), compounding opportunities (related topics already partially covered), and graph proximity search for hybrid retrieval.

ChromaDB Vector Store

Two primary collections:

  • creator_dna — 768-dimensional DNA fingerprint embeddings, one per creator
  • content_embeddings — Content piece embeddings for semantic similarity search

Hybrid Search Algorithm

final_score = 0.6 * vector_similarity + 0.4 * graph_proximity

# vector_similarity: ChromaDB cosine similarity (0–1)
# graph_proximity:   Neo4j shortest path distance, normalized (0–1)
# Both searches run concurrently via asyncio.gather()

Creator DNA System

The DNA fingerprint system is the unique differentiator of Creator OS. It ensures all AI-generated content sounds authentically like the creator.

Analysis Pipeline

  1. Transcript Collection — Fetch 20–100 video transcripts via YouTube Captions API
  2. LLM Analysis — Claude analyzes each transcript for 14 stylistic dimensions
  3. Fingerprint Aggregation — Compute means, modes, and frequency-ranked attributes across all transcripts
  4. Embedding Generation — Convert fingerprint to 768-dim vector stored in ChromaDB
  5. Style Transfer — Build a conditioning prompt block injected into every content-generating agent

Confidence Scoring

Videos Analyzed → Confidence Score
  1 video       → 15%
  5 videos      → 55%
 10 videos      → 75%
 20 videos      → 90%
 50+ videos     → 99%

Formula: confidence = min(0.99, log(n+1) / log(51) * 0.99)

Below 50% confidence, the DNA prompt uses a "low confidence" template with more creative latitude. Above 50%, the full conditioning prompt is injected.

Key Design Decisions

  • App Router — Next.js 14 App Router with server components where possible
  • shadcn/ui — Copy-paste components (not a dependency) for full control
  • Dark/Light Theme — CSS variables via Tailwind, system preference detection
  • SSE for Streaming — Agent output streamed via Server-Sent Events for real-time typing
  • WebSocket for Status — Agent pipeline status updates via persistent WebSocket connection
  • Recharts — Analytics charts (line, bar, radar) for performance and DNA visualization

Security Design

  • OAuth 2.0 — YouTube/Google OAuth via NextAuth.js; no passwords stored
  • Token Encryption — YouTube API tokens encrypted at rest using Fernet symmetric encryption
  • JWT Sessions — Short-lived access tokens with refresh rotation
  • Rate Limiting — Per-user, per-endpoint limits via Redis sliding window
  • YouTube Quota Tracking — Enforces 10,000 unit/day quota with operation cost mapping
  • CORS — Restricted to frontend origin only
  • Input Validation — All inputs validated via Pydantic models

Key Design Decisions

Why LangGraph over plain LangChain?

LangGraph provides typed state machines with parallel execution, conditional routing, and built-in persistence — essential for multi-step agent pipelines with human-in-the-loop gates.

Why Neo4j + ChromaDB + PostgreSQL?

Each database excels at its role: PostgreSQL for relational data, Neo4j for relationship traversal (content gaps, topic authority), ChromaDB for fast vector similarity. Hybrid search combines vector + graph signals.

Why Claude primary + OpenAI fallback?

Claude excels at long-form creative writing and instruction following (critical for DNA-conditioned scripts). OpenAI provides a reliable fallback if Claude is unavailable.

Why Celery over async background tasks?

Celery provides reliable scheduled execution, retry logic, result storage, and monitoring. Async tasks in FastAPI lack persistent scheduling and would couple background work to the API process.
